# Zen Cart: Admin Add User v1.1.0

Lets a store admin capture minimal customer details (name and email; phone is optional) one-by-
one or via CSV bulk upload, optionally assigning a pricing group and/or a wholesale level. Each
new customer is emailed an activation link; clicking it activates the account immediately and
sends the customer to a standard Zen Cart login, where they fill in their address and anything
else themselves using your store's own account pages.

Compatible with Zen Cart v2.0.0 through the current v3.0.0-track `master`, packaged as an
encapsulated plugin (`zc_plugins/`). See `readme.html` for full installation instructions and
version history.
