Formatting a CSV File for Bulk Upload (Admin Add User, Zen Cart 2.0.0 - 3.0.0)

The headings can be in any column-order as long as they are contained in the first non-blank row of the uploaded file. This is deliberately a short list - just enough to get someone started. Every customer added, whether from this file or the single-entry form, starts pending and is always emailed an activation link (see the main readme's "How Activation Works" section) - there is no way to bulk-import an already-active customer with this tool. The heading values and their expected data are:

Heading Title Description
first_name Required. The minimum length is controlled by Configuration->Minimum Values->First Name.
last_name Required. The minimum length is controlled by Configuration->Minimum Values->Last Name.
email Required, the minimum length is controlled by Configuration->Minimum Values->Email Address. Regardless of minimum length, the value must be a "proper" email address and must not already be used by another customer in your database.
telephone Optional - it can be left blank, and the customer is given the chance to add or correct it when they complete activation. If a value is given here, it must conform to the format of a world phone number.
customers_group_pricing Optional. A number that identifies the group_id of the "Customers Group Pricing" group to which the customer should be associated. A value of 0 (or a blank/missing column) means no group, i.e. pricing group --none--.
wholesale_level Optional plain number for Configuration->My Store->Wholesale Pricing (only meaningful if that setting isn't false); matches the same field on your admin's Customers edit screen. Enter 0 (or leave the column blank/missing) for none, or a number matching the wholesale settings already used in your store - Zen Cart core defines no fixed list of what each number means; that's entirely up to your own pricing setup.

Everything else - address, gender, date of birth, company, coupon, newsletter, etc. - is never part of this file. Address and the rest are entered by the customer themselves, via your storefront's own account pages once they've activated and logged in; coupons aren't currently collected at entry at all. This keeps this file focused on the minimum needed to get someone started, and keeps mistakes in anything more sensitive (like address) from being attributable to the store. A tax/resale number, if you need to record one for a wholesale customer, can only be entered via the single-entry admin form, not this file.

If you don't know how to make a Comma-Separated Values (CSV) file, then use Microsoft Excel as normal to create a spreadsheet. When you are ready to save, choose file>save as, then at the bottom there will be a 'Save as type' option; choose 'CSV (comma delimited)' and then press Save. Answer yes to any warnings and there you have it... a CSV!
